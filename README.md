## Why this wiki?

The creation of this wiki was necessary to join all the essentials informations of custom ressources and lore in one place.

## Why I have choose the Material theme for MkDocs as boillerplate for this wiki?

My choice on Material for Mkdocs is because I needed an esay customable but stylish looking wiki for the purpose of the use for the users. Instead using a classic framework for wikis or using a wiki hoster like Fandom, I wanted a complete control and an esy way to create a doc.

Also i wanted to make it easy to make the wiki to be hosted by Github.
